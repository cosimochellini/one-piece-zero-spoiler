# Fruit screenshot provenance

The four `fruits-320-before.png`, `fruits-320-after.png`,
`fruits-1280-before.png` and `fruits-1280-after.png` files were replaced on
2026-10-22 as part of #732 to remove the previous Gum-Gum drawing from current
committed screenshot copies.

Both columns now show the **current production-preview UI**, in English at
episode 1150. The `before` files show the start of the Paramecia group; the
`after` files show the first fruit while the group heading is pinned during
scrolling. The filenames remain so existing links resolve. They no longer
provide an implementation-before/implementation-after comparison for #500.

The original #500 screenshots can be identified in repository history, for
example at `6a943d2:docs/media/issue-500/`. They showed the earlier canonical
fruit depiction and are historical evidence, not current product imagery or a
permission claim. They have not been copied to another current asset directory.
The character, filler and place screenshots in this folder are unchanged by #732
and retain their original historical meaning.
